Install Leggio

Leggio is on its way to the Chrome Web Store. Until it arrives, you can install it yourself. It takes about a minute.

Download Leggio

Version 1.0.0 · ZIP, 4.3 MB · Free

  1. Unzip it

    Open leggio-1.0.0.zip from your downloads. You’ll get a folder called leggio-1.0.0. Move it somewhere it can stay, such as Documents: Chrome runs Leggio from that folder.

  2. Open Chrome’s extensions page

    Type this into Chrome’s address bar and press Enter. Websites aren’t allowed to link there, so it has to be typed or pasted.

    chrome://extensions

  3. Turn on Developer mode

    It’s the switch in the top-right corner of the extensions page.

  4. Load Leggio

    Click Load unpacked and choose the leggio-1.0.0 folder. Leggio joins your extensions. Pin it from the puzzle-piece menu so it’s easy to find.

Good to know

  • Leggio needs Chrome 138 or later on a computer. That’s when Chrome’s built-in translation arrived.
  • To try it, open a PDF or a web page in the language you’re learning, select a word and press T.
  • This copy won’t update itself. When Leggio is in the Chrome Web Store, install it from there and remove this one.
  • Chrome treats the two as different extensions, so your saved words won’t move across on their own. Before you switch, open Leggio’s word list and choose Export CSV to keep a copy.
